# Spec 03 — Frontend Scaffold (Next.js + shadcn/ui)

## Goal
Scaffold a Next.js 14 frontend with App Router, TypeScript strict mode, Tailwind CSS, **shadcn/ui**, Sonner toasts, and the base libraries needed to build a premium Kanban UI.

## Context
- **UI design contract: read `/DESIGN.md` first.** Every component, color, font, and spacing decision must follow it. Do not deviate.
- **Component library: shadcn/ui** (Radix + Tailwind). All primitives come from `src/components/ui/`. No Material/Chakra/MUI/Bootstrap.
- **Icons: Lucide React** (bundled with shadcn)
- **Toasts: Sonner** (installed via shadcn)
- Frontend will live in `frontend/` directory
- Will consume the NestJS API from Spec 02 at `http://localhost:3001/api` (configurable)
- Drag-and-drop will use `@dnd-kit/core` + `@dnd-kit/sortable` (added in Spec 10)
- Form handling: `react-hook-form` + `zod` (for forms with validation)

## Constraints
- Use `create-next-app` to scaffold base, then `npx shadcn@latest init` to configure shadcn, then `npx shadcn@latest add <components>` for primitives
- **TypeScript strict mode ON**
- **Tailwind CSS** for all styling (no CSS modules, no styled-components, no inline styles)
- **shadcn/ui for ALL primitives** — no Material/Chakra/MUI/Bootstrap. Custom code only for app-specific composites.
- **Inter font** via `next/font/google` — variable, with `subsets: ['latin']`
- **App Router** (not Pages Router) — all routes under `app/`
- **CSS variables for colors** — never hardcode hex in components. All colors via Tailwind tokens defined in `globals.css`
- **Dark mode supported** via `next-themes`, `class="dark"` strategy on `<html>`
- API client: native `fetch` wrapped in `lib/api.ts`, JWT from `localStorage`, throws on non-2xx
- Use **React 18**, no experimental features
- All shadcn components installed at scaffold time so later specs can import freely
- Folder structure:
  ```
  src/
    app/                  # routes
    components/
      ui/                 # shadcn primitives (auto-generated, owned)
      *.tsx               # app components
    lib/                  # api client, utils, types
    hooks/                # custom hooks
    contexts/             # React contexts (AuthContext added in Spec 04)
  ```
- **Loading and error states** — every page handles all three (see DESIGN.md)
- **No emoji as icons** — use Lucide (`lucide-react` is shadcn's default)
- **No gradients**, no `bg-blue-500`, no `shadow-xl` everywhere — see DESIGN.md anti-patterns
